# Sentinel DedSec Edition v6

## 18 interactive sections

1. NET — nearby Wi-Fi scan and signal sorting.
2. DEVICES — Android model, battery and network diagnostics.
3. LENS — system camera and local photo preview.
4. CONSOLE — allow-listed local diagnostic commands.
5. MAP — OpenStreetMap markers and phone location.
6. TOOLS — password lab, generator, FNV-1a and Base64.
7. PULSE — DNS response and local link test.
8. ARCHIVE — cached Ubisoft promo gallery with glitch effects.
9. SENSORS — live accelerometer, gyroscope and magnetometer.
10. VAULT — secure local note backed by Android secure storage.
11. NOTES — persistent local field log.
12. QR LAB — live QR scanner and QR generator.
13. FILES — Android picker, streamed metadata/hash and text preview.
14. COMPASS — magnetic bearing and field strength.
15. SIGNAL — connectivity change watcher and Wi-Fi link details.
16. PERMISSIONS — permission status, request buttons and app settings.
17. TIME — live device clock, stopwatch and countdown.
18. CLIPBOARD — user-triggered read/write/clear and text metrics.

## Build

- Version: `3.0.0+4`
- Minimum Android: 5.0 / API 21
- Release command: `flutter build apk --release`
- GitHub Actions artifact: `sentinel-marcus-hub-release`

Sentinel remains a fan-made Android application, not an operating system,
launcher, root shell or official Ubisoft product.
